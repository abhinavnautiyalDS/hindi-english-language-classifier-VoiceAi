# Data Directory

- `raw/`: original source downloads; keep local by default.
- `interim/`: source-specific cleaned datasets.
- `processed/four_class/`: canonical merged splits and audit outputs.
- `processed/legacy/`: previous processed data if/when imported.
- `synthetic/punjabi_hindi/`: Punjabi-Hindi synthetic CSV and generation metadata.
- `manifests/`: source registry and acquisition log.
- `legacy/`: previous dataset snapshots and notes.

Read [DATASET_PLAN.md](../DATASET_PLAN.md) before adding data. Preserve provenance and licensing for every source.
